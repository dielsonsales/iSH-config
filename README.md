## Running the script:

### For iSH

```sh
curl -o setup.sh https://raw.githubusercontent.com/dielsonsales/iSH-config/refs/heads/main/setup.sh && sh setup.sh && rm setup.sh
```

### For common Alpine

```sh
curl -o setup-alpine.sh https://raw.githubusercontent.com/dielsonsales/iSH-config/refs/heads/main/setup-alpine.sh && sh setup-alpine.sh && rm setup-alpine.sh
```
